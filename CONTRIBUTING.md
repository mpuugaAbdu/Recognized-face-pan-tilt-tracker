# Contributing

Thanks for helping improve Office Assistant Face Tracker.

1. Open an issue describing the change or safety concern.
2. Create a focused branch and keep unrelated changes separate.
3. Preserve existing SPDX license headers.
4. Never commit face databases, enrollment photos, secrets, or personal data.
5. Test pan/tilt changes with the mechanism clear of obstructions.
6. Test drive changes with the wheels raised first, then at low speed in a clear area with an emergency stop available.
7. Document wiring, behavior, and calibration changes in the README.

Pull requests should explain what changed, how it was tested, and any remaining hardware assumptions.
